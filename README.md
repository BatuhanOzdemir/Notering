# 📝 NotesApp — Android Notes Application (Java, Room, MVVM)

NotesApp is a simple yet fully functional Android notes application built using **Java** and **modern Android architecture components**.  
The app demonstrates full CRUD operations with **Room Database**, **MVVM architecture**, and **RecyclerView**, following clean architecture principles.

This project is designed as a portfolio project for junior Android developers.

---

## 🚀 Features

- Create, read, update, and delete notes (CRUD)
- Local data persistence using Room (SQLite)
- MVVM architecture (ViewModel + Repository + LiveData)
- RecyclerView for displaying notes
- Swipe-to-delete functionality
- Edit existing notes on item click
- Automatic UI updates via LiveData
- Clean and simple user interface
